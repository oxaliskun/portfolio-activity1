ZRAM Turbo Booster — Magisk Module · Creator

GitHub · Android 6+ · Performance
Problem Statement

Phones killed apps too aggressively, reloaded on switch, and lagged in games due to poor RAM management. Needed tuned ZRAM and memory reclaim for smoother multitasking without new hardware.

Technologies / Tools Used
Shell ZRAM (lz4/lzo) Linux Kernel LMK FSCC Magisk
Key Contributions
  • Tuned ZRAM compression (lz4 default, 0–6GB configurable) with ~2.8x ratio
  • Fixed QTI 32-app limit, re-tuned LMK thresholds and watermark/swappiness
  • Added FSCC file-cache pinning for framework/SystemUI/launcher and AdjShield app protection
  • Optimized kswapd to efficient cores for battery; config via /sdcard/Android/panel_zram.txt
Outcome & Impact

4GB device now multitasks like 6–8GB — apps stay alive, gaming frame drops reduced, task switching faster. Daily-driver tested on SD 6xx/7xx/8xx & MediaTek. Shell 28,860. Configurable per RAM size.

Evidence: 🔗 github.com/oxaliskun/Zram-Module Shell 28,860 · 6GB max ZRAM
